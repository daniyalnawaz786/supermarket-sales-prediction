## 🌟 Project Overview

A **powerful and visually stunning** supermarket sales analytics platform built with Streamlit. This enterprise-grade dashboard helps store managers make data-driven decisions through advanced forecasting, intelligent product recommendations, and comprehensive analytics.

With its **cosmic-themed professional design**, interactive visualizations, and real-time analytics, managing sales has never been more engaging!

## ⚡ Quick Start

### Prerequisites
- Python 3.8 or higher
- pip (Python package manager)
- Virtual environment support

### 📥 Installation

**For Linux/macOS:**
```bash
# Make setup script executable
chmod +x setup.sh

# Run the setup script
./setup.sh

# Activate virtual environment
source venv/bin/activate

# Navigate to app directory and run
cd app
streamlit run app.py
```

**For Windows:**
```bash
# Run the setup script
setup.bat

# The app will launch automatically
```

**Manual Setup (all platforms):**
```bash
# Create virtual environment
python -m venv venv

# Activate it
# On Linux/macOS:
source venv/bin/activate
# On Windows:
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run the app
cd app
streamlit run app.py
```

### 🌐 Access the Dashboard
Once running, Streamlit will provide a local URL (usually `http://localhost:8501`)

## 🧠 How It Works

### Data Pipeline
1. **Load Data** - Reads historical supermarket sales data
2. **Process** - Cleans and transforms data for analysis
3. **Aggregate** - Groups data by category, product, and time period
4. **Visualize** - Renders interactive charts with Plotly
5. **Forecast** - Uses ML model to predict future sales

### Feature Flow
```
Raw CSV Data → Data Processing → Filtering (by date/category) 
→ Aggregation → Visualization → Interactive Dashboard
```
